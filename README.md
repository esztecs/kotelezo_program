A kötelező programom témájának a harmadikat választottam, a mini könyvtár nyilvántartó programot.
Ezeket a funkciókat raktam bele: könyv hozzáadás, listázás, keresés és kilépés a programból.
Json fájlt hoztam létre a könyvek tárolására.
A program indítása után lehet választani számmal, hogy melyik funkciót szeretnénk használni. 
Ha valamit nem jól adtunk meg, jelzi ezt a program és újrakéri.
Listázásnál számozással jeleníti meg az elmentett könyveket és azok szerzőit.
Keresésénél megadhatjuk a könyv címét, vagy szerzőjét, részleges keresésre is ad ki találatot.
4-es számmal lehet kilépni a programból.
